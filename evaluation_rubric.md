# LLM Response Evaluation Rubric

## Purpose

This rubric provides a consistent method for evaluating AI-generated responses. It is designed for a small portfolio demonstration of LLM evaluation and quality assurance.

## 1. Accuracy

Measures whether the response contains correct factual information.

- **5:** All important factual claims are correct.
- **4:** Mostly correct, with a minor issue.
- **3:** Partly correct, with a noticeable error or omission.
- **2:** Contains significant factual errors.
- **1:** Fundamentally incorrect or misleading.

## 2. Relevance

Measures how directly the response answers the user's question.

- **5:** Directly answers the request.
- **4:** Mostly relevant, with minor unnecessary details.
- **3:** Partly addresses the request.
- **2:** Mostly misses the user's intent.
- **1:** Does not meaningfully answer the request.

## 3. Instruction-following

Measures whether the response follows explicit instructions, including length, format, and requested number of items.

- **5:** Follows all instructions.
- **4:** Has a minor deviation.
- **3:** Misses one meaningful requirement.
- **2:** Misses several important requirements.
- **1:** Fails the main instruction.

## 4. Clarity

Measures readability, organization, and ease of understanding.

- **5:** Clear, concise, and well organized.
- **4:** Clear overall, with minor wording issues.
- **3:** Understandable but awkward or poorly organized.
- **2:** Difficult to follow.
- **1:** Very unclear.

## Evaluation Procedure

1. Read the prompt carefully.
2. Identify the user's explicit requirements.
3. Score the response on all four dimensions.
4. Explain each significant deduction with specific evidence.
5. Verify factual claims when necessary.
6. Review scores for consistency.

## Overall Score

Calculate the arithmetic mean of the four dimension scores and round to one decimal place.

A high average does not automatically mean a response is acceptable. Record serious factual errors and instruction failures separately.

## Quality Principles

- Apply the same criteria consistently.
- Base ratings on evidence rather than personal preference.
- Flag uncertainty instead of guessing.
- Separate factual errors from style preferences.
- Document the reasoning behind important judgments.

## Limitations

Human ratings involve judgment and can differ between evaluators. This rubric is a demonstration tool, not a validated industry benchmark.
